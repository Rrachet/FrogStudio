# Code of Conduct

## Our standard

Contributors and collaborators are expected to communicate respectfully and professionally.

Examples of unacceptable behaviour include harassment, discrimination, personal attacks, deliberate disruption, publishing private information, and other conduct that would make the project unsafe or unwelcoming.

## Reporting

If you experience or observe unacceptable behaviour, contact the project maintainer privately. Include enough context to investigate the report while avoiding unnecessary personal information.

## Enforcement

Project maintainers may remove comments, reject contributions, close discussions, or restrict participation when behaviour violates this code of conduct.

## Scope

This code applies to project discussions, issues, pull requests, reviews, and other project spaces operated by the maintainers.
